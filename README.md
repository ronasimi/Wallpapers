# Personal Wallpapers

A curated collection of personal wallpapers, primarily in 1080p resolution.

## Overview

This repository contains a collection of wallpapers suitable for desktop environments and display systems. Most images are in 1920×1080 (1080p) resolution, optimized for standard monitors and laptops.

## Contents

- **Wallpapers**: High-quality images in PNG/JPG format
- **Resolution**: Primarily 1920×1080 (1080p)
- **Categories**: Organized by theme or style as needed

## Usage

### Linux Desktop Environments

#### GNOME
1. Right-click on the desktop
2. Select "Change Background"
3. Choose "Pictures" and navigate to the wallpaper
4. Click to set as wallpaper

#### KDE Plasma
1. Right-click on the desktop
2. Select "Configure Desktop and Wallpaper"
3. Click "Wallpaper" tab
4. Browse and select your wallpaper

#### Hyprland / Other WMs
Set wallpaper using tools like:
```bash
hyprpaper
feh
nitrogen
```

### Windows/macOS
Copy wallpaper files to your Pictures folder and set through system settings.
